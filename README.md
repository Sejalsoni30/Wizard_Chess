# ♟️ Wizard's Chess 3D | Arcane WebGL Engine

A fully procedural 3D Wizard's Chess web application featuring arcane stone animations, dynamic lighting, combat destruction effects, Web Audio synthesis, and chess rule validation.

Built with **Three.js**, **chess.js**, **GSAP**, **Web Audio API**, and **Material Design 3**.

---

## ✨ Features

- **🧙 Procedural 3D Chess Pieces & Board**: Rendered in real-time with custom materials, stone texturing, and atmospheric lighting.
- **⚡ Spellcasting & Combat Animations**: Dynamic capture animations with destruction particles and physics-based impacts powered by GSAP.
- **🔊 Arcane Web Audio Synthesizer**: Procedural sound effects for moves, captures, check, and victory.
- **♟️ Authentic Chess Logic**: Powered by `chess.js` supporting legal move validation, check, checkmate, castling, en passant, and pawn promotion.
- **🎥 Multiple Dynamic Camera POVs**: Switch between Free Orbit, White's Perspective, Black's Perspective, and Top-down Tactical View.
- **💎 Material Design 3 Glassmorphism HUD**: Responsive, sleek UI showing turn indicator, captured pieces tray, move history, and sound controls.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- npm or yarn

### Installation & Run

1. Navigate to the project directory:
   ```bash
   cd wizards-chess-3d
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Open the displayed local URL in your browser (typically `http://localhost:5173`).
